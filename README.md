# 📊 Excel Sales Dashboard

## ABC Executive Summary & Profitability Dashboard

### 📌 Project Overview
This project is an interactive Sales Dashboard created using Microsoft Excel. It helps analyze sales performance, revenue, profit, and business trends.

### 🎯 Project Objectives
- Analyze total revenue and profit.
- Track monthly revenue and profit.
- Identify top-performing countries.
- Compare revenue across sales channels.
- Analyze regional performance.
- Understand product category performance.

### 🛠️ Tools & Technologies Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis
- Data Visualization

### 📈 Key Performance Indicators (KPIs)
- Total Revenue: $616,761
- Total Profit: $283,248
- Gross Profit Margin: 45.93%
- Total Units Sold: 6,397
- Total Orders: 2,597
- Cost of Goods Sold (COGS): $333,513

### 📊 Dashboard Features
1. Monthly Revenue and Profit Analysis
2. Top 5 Countries by Revenue
3. Revenue Share by Channel
4. Region-wise Comparison
5. Country-wise Map
6. Product Category Analysis
7. Interactive Slicers for Product Category, Country, and Quarter
